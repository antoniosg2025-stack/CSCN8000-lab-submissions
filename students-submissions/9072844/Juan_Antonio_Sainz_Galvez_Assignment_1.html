Assignment 1 – Parkinson's Disease Classification¶

Name: Juan Antonio Sainz Galvez Course: CSCN8000 – Artificial Intelligence Algorithms and Mathematics Assignment: Assignment 1

Problem statement: Given the symptoms exhibited in a patient (voice-recording measurements) and a database of anonymized patient records, predict whether the patient is likely to have Parkinson's disease. A model like this could be used by a program to give decision support to medical professionals.

Dataset: UCI Machine Learning Repository – Parkinson's Disease Classification (id 470) https://archive.ics.uci.edu/dataset/470/parkinson+s+disease+classification

        zf.extractall(DATA_DIR)

    for rar in DATA_DIR.glob("*.rar"):

    csv_files = list(DATA_DIR.rglob("*.csv"))
    if not csv_files:
        raise FileNotFoundError("No CSV found after extracting the UCI files.")
    if csv_files[0] != DATA_FILE:
        csv_files[0].replace(DATA_FILE)
print("Dataset file:", DATA_FILE.resolve())

Findings of the analysis

  • Each patient appears 3 times (three voice recordings per person). This matters for the train/test split: if the same person is in training and in testing, the model "recognizes the person" and the accuracy looks better than it really is (data leakage).
  • There are about 750 numeric features per recording, measured on very different scales (some near 0.001, others in the thousands), so the distance-based models (KNN, SVM) need standardized data.
  • The classes are imbalanced (around three Parkinson's patients for every healthy one), so besides accuracy we also look at precision, recall and F1 per class.

iii. Data Standardization¶

StandardScaler transforms every feature to mean 0 and standard deviation 1: $z = \frac{x - \mu}{\sigma}$.

The scaler is fitted only on the training data and then applied to the test data. It is placed inside a scikit-learn Pipeline together with each model, so the test set never influences the scaling (no leakage). The effect of the standardization is shown right after the split in Question 2.

Question 2 – Use 80% of samples as training data¶

We use GroupShuffleSplit with test_size=0.2, grouping by patient id, so all three recordings of a patient go to the same side (train or test). This gives ~80% of the samples for training and tests the models on patients they have never seen, which is how the system would be used with a new patient.

Question 3 – Model Training¶

Each model is a Pipeline: StandardScaler → classifier.

  • K-Nearest Neighbors (KNN): classifies a recording by the majority class of its 5 closest recordings.
  • Random Forest: many decision trees trained on random subsets; the final answer is the vote of all trees.
  • Support Vector Machine (SVM): finds the boundary with the widest margin between classes (RBF kernel).
  • Decision Tree: a single tree of yes/no questions on the features.
In [12]:
models = {
    "KNN": KNeighborsClassifier(n_neighbors=5),
    "Random Forest": RandomForestClassifier(n_estimators=300, random_state=RANDOM_STATE, n_jobs=-1),
    "SVM": SVC(kernel="rbf", C=1.0, gamma="scale", random_state=RANDOM_STATE),
    "Decision Tree": DecisionTreeClassifier(random_state=RANDOM_STATE),

pipelines = {}
for name, model in models.items():
    pipe = Pipeline([("scaler", StandardScaler()), ("model", model)])

  • Best model: Random Forest (83.0% accuracy), followed closely by SVM (81.0%). Both detect 97% of the Parkinson's recordings and miss only 3 of 111, which is the most important result for a decision-support tool, because a missed Parkinson's case (false negative) is the most costly error.
  • The weak point of all the models is the healthy class. Random Forest recognizes only 45% of the healthy recordings (19 of 42) and flags the other 23 as Parkinson's. The cause is the class imbalance: about 75% of the samples are Parkinson's, so the models lean toward predicting the disease. A model that always answered "Parkinson's" would already reach ~73% accuracy on this test set, so the real gain of Random Forest is about 10 percentage points, coming mostly from correctly identifying some healthy patients.
  • Decision Tree has the lowest accuracy (76.5%) and misses 17 Parkinson's cases, but it is the most balanced model for the healthy class (55% recall), because a single tree overfits less toward the majority class.
  • KNN sits in the middle (79.7%) and misses 7 Parkinson's cases.
  • The predictive system in Question 5 shows the same pattern: the Parkinson's patient was diagnosed correctly by three of the four models, while the healthy patient was recognized only by KNN.
  • Because the split keeps every patient in only one set, these numbers are an honest estimate for new patients. Possible improvements are class weights (class_weight="balanced"), tuning hyperparameters with grouped cross-validation, and combining the three recordings of a patient into one diagnosis by majority vote.
